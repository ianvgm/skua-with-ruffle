# Skua + Ruffle - build no seu GitHub

1. Faca um fork de https://github.com/auqw/Skua para a sua conta.
2. Copie o conteudo desta pasta para a raiz do seu fork (mantendo as pastas).
3. Coloque o seu skua.swf em `prebuilt/skua.swf`.
4. Commit + push.
5. No GitHub: aba Actions > "Build Skua (Ruffle)" > Run workflow.
6. Ao terminar (~10 min), baixe o artefato "Skua-Ruffle-x64" no fim da pagina da execucao, extraia e rode Skua.exe.
